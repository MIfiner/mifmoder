# LightGram V1 — План реализации и архитектурная дорожная карта

LightGram V1 — независимый клиент Telegram для iOS, разработанный на базе официального репозитория `TelegramMessenger/Telegram-iOS` с интеграцией уникального брендинга (тёмная графитовая эстетика с золотисто-жёлтыми акцентами) и адаптированных возможностей приватности (Ghost Mode, Spy Mode, умные фильтры, инструменты групп).

## Фаза D: Функционал AyuGram (Ghost Mode, Spy Mode, Фильтры)
- [x] **LightGram Settings & Core State (`LightGramSettings.swift`):**
  - Централизованное управление опциями приватности и кастомизации.
- [x] **Ghost Mode (Призрачный режим):**
  - Опция подавления отправки прочтения сообщений (`suppressReadHistory`).
  - Кнопка ручной отметки прочтения («Отметить прочитанным»).
  - Опция подавления отправки статуса набора текста (`suppressTyping`).
  - Опция скрытного просмотра историй (`suppressStoryViews`).
  - Честное информирование пользователя об ограничениях сервера Telegram.
- [x] **Spy Mode (Архив удалённых и изменённых сообщений):**
  - Локальный аудит удалений: маркировка удалённых сообщений специальным бейджем без стирания из локального просмотра.
  - История редактирования: фиксация версий текста сообщений с возможностью просмотра ревизий.
  - Управление архивом: квоты хранилища (TTL 7/30/90 дней), очистка локальных данных.
- [x] **Smart Folders & Фильтры:**
  - Быстрые фильтры чатов: Личные переписки, Группы, Каналы, Боты, Непрочитанные.
- [x] **Инструменты групп и ботов:**
  - Панель шаблонов сообщений и быстрых команд.
- [x] **Безопасная пересылка:**
  - Режим быстрой пересылки без указания авторства (в разрешённых чатах).
  - Строгое соблюдение защищённых чатов и системной безопасности.
