# LIGHTGRAM DESKTOP — FEATURE PARITY & ARCHITECTURE SPECIFICATION
## Таблица соответствия возможностей LightGram iOS и реализации на LightGram Desktop (Windows, macOS, Linux)

---

## 1. Введение и Архитектурный Обзор

**LightGram Desktop** — полнофункциональный кроссплатформенный клиент для настольных операционных систем (Windows 10/11, macOS 12+, Linux x86_64/arm64), переносящий всю философию, дизайн-код iOS 27 / Liquid Glass и эксклюзивный функционал LightGram iOS в высокопроизводительное нативное десктопное приложение.

### Ключевые требования к архитектуре Desktop:
1. **Нативная производительность и минимальное потребление RAM**: Реализация на **C++20 и Qt 6** гарантирует мгновенный запуск, 60/120 FPS анимации интерфейса и потребление памяти ~40–80 МБ (в 5–8 раз меньше Electron-аналогов).
2. **Полная совместимость с Telegram API / MTProto**: Использование официального протокольного стека TDLib (Telegram Database Library v1.8.x) и MTProto, полностью совместимого с серверами Telegram. Никаких самодельных парсеров протокола.
3. **Строгая изоляция от кодовой базы iOS**: Десктопный клиент располагается в выделенном каталоге `desktop/`, не затрагивая сборочные скрипты Bazel, конфигурации Xcode и исходники iOS.
4. **Фирменный стиль iOS 27 / Liquid Glass**: Акриловые и слюдяные полупрозрачные поверхности (Mica / Acrylic на Windows 11, NSVisualEffectView Vibrancy на macOS, KWin/Mutter blur на Linux), мягкие тени, скругления 12–20px, адаптивная темная и светлая палитры.
5. **LightGram Studio**: Встроенная дизайн-студия для кастомизации любых цветовых токенов, радиусов, прозрачности и обоев с живым предпросмотром, HEX/RGB палитрой и поддержкой 10 встроенных тем.

## 3. Детальное описание ключевых десктопных модулей

### 3.1. LightGram Studio (Редактор внешнего вида)
LightGram Desktop предоставляет интерактивную студию тем:
- **10 предустановленных тем оформления:**
  1. `LightGram Original` — классический тёмный глубокий графит с фирменным золотисто-янтарным акцентом (`#EDB400`).
  2. `AMOLED Black` — абсолютно чёрный фон (`#000000`) с максимальной контрастностью.
  3. `Midnight` — глубокий сапфирово-синий фон (`#0A0F1D`) с акцентом электрик-индиго.
  4. `Graphite` — премиальный матовый серый титан (`#18181B`).
  5. `Arctic` — морозная светлая тема со стеклянными небесно-голубыми переливами (`#007AFF`).
  6. `Emerald` — благородный изумрудно-зелёный акцент (`#2ECC71`) на тёмном нефритовом фоне.
  7. `Violet` — неоновый фиолетовый акцент (`#AF52DE`) на глубоком аметистовом фоне.
  8. `Sunset` — тёплый кораллово-оранжевый градиент (`#FF5E3A`).
  9. `Crimson` — рубиново-красный акцент (`#FF3B30`) в стиле агрессивного хайтека.
  10. `Pure White` — ультрачистая минималистичная светлая тема (`#FFFFFF`).
- **Тонкая настройка каждого элемента:**
  - Акцентный цвет (Primary & Secondary).
  - Фон окна и боковой панели.
  - Цвет входящих и исходящих бабблов сообщений.
  - Цвет текста, кнопок, иконок и бейджей непрочитанного.
  - Ползунки: Corner Radius (0–28px), Glass Opacity (0.2–1.0), Blur Radius (0–30px).
- **Импорт / Экспорт:**
  - Сохранение пользовательских схем в файл `.lightgram-theme` (формат JSON).
  - Обмен темами между Desktop и мобильной версией iOS.

### 3.2. Spy Mode & Anti-Recall на Десктопе
- Реализация не нарушает политику памяти и безопасности Telegram API: сохранение удалённых сообщений производится в локальную базу данных пользователя на диске (`~/.local/share/LightGram/spy_archive.json` или `%APPDATA%/LightGram/`).
- Сообщения, удалённые собеседником или администратором группы:
  - Остаются на своих исходных временных позициях в ленте чата.
  - Обводятся аккуратной тонкой рамкой цвета `#FF3B30` с подсветкой фона.
  - Снабжаются компактным неинвазивным значком `🔴 DELETED`.
  - При правом клике открывается меню: «Подробности удаления», «Копировать исходный текст», «Удалить локально».
- Отредактированные сообщения:
  - Сохраняют всю историю изменений.
  - Помечаются меткой `🟡 EDITED` с номером ревизии.
  - При клике на плашку открывается всплывающее окно со сравнением текста «Было / Стало».

### 3.3. Ghost Mode (Режим невидимки)
- Полный контроль над сетевой активностью:
  - Чтение диалогов без посылки RPC `messages.readHistory`.
  - Запрет трансляции статуса набора текста («печатает...», «записывает голосовое...»).
  - Скрытие онлайн-статуса пользователя.
  - Скрытный просмотр историй (Stories).
  - Опция «Отмечать прочитанным при отправке ответа» (Mark as read on reply).

### 3.4. Эксклюзивные функции Desktop
- **Вкладки чатов (Chat Tabs):** возможность открывать несколько диалогов во вкладках над лентой сообщений, как в браузере.
- **Мульти-окна (Multi-Window):** открепление любого чата или звонка в отдельное самостоятельное окно ОС.
- **Быстрый доступ и Hotkeys:**
  - `Ctrl+K` / `Cmd+K` — глобальный быстрый поиск чатов и команд.
  - `Ctrl+1..9` — переключение между первыми чатами/вкладками.
  - `Ctrl+Shift+G` — быстрое включение/отключение Ghost Mode.
  - `Ctrl+Shift+S` — открытие LightGram Studio.
  - `Ctrl+Shift+A` — открытие Spy Archive.
- **Drag & Drop:** перетаскивание файлов любого типа прямо в окно чата для мгновенной отправки как фото, видео или документ.
- **Системный трей и автозапуск:** сворачивание в область уведомлений Windows/macOS/Linux, автозапуск при старте системы.

## 4. Безопасность и хранение данных

1. Все авторизационные данные хранятся через стандартный механизм защищённого хранилища TDLib (TDLib Key-Value Keystore) с аппаратным или шифрованным ключом.
2. Никаких сторонних прокси-серверов или баз данных: взаимодействие происходит **напрямую между клиентом пользователя и официальными дата-центрами Telegram (MTProto DC1–DC5)**.
3. Локальные архивы Spy Mode и Media Vault могут быть защищены мастер-паролем, предотвращая просмотр удалённых сообщений третьими лицами, имеющими доступ к компьютеру.

## 5. План сборки для Windows, macOS и Linux

- **Linux:** Сборка нативного бинарника `lightgram-desktop` (ELF), упаковка в AppImage и deb-пакет.
- **Windows:** Сборка под MSVC / MinGW x64, поддержка установщика NSIS / MSIX и переносимой (Portable) версии.
- **macOS:** Сборка нативного Universal 2 Bundle (`LightGram.app`) для Apple Silicon (M1-M4) и Intel x86_64, интеграция с нативным окном macOS (Cocoa blur).
